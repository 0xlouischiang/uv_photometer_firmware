# NEMA 4X 机柜 —— 布局检查模型

`AMMONIA_FIA_SENSOR_DESIGN.md` §8.4 / BOM 第 32 项。外壳是**买的**成品柜，不
是加工件；这个模型的作用是核对内部三层机箱能不能真的塞进那只柜子里，不是
拿去下单加工外壳。

## 文件

| 文件 | 用途 |
|---|---|
| `cabinet.py` | 参数化建模脚本，含 53 项几何自检 |
| `cabinet_shell.step` | 外壳单独一份，用于比对真实产品的规格书 |
| `cabinet_assembly.step` | 装配体（外壳 + 门 + 三层机箱 + 泵/阀/瓶子占位元件），用于检查间隙 |
| `cabinet_shell.FCStd` / `cabinet_assembly.FCStd` | FreeCAD 原生文件 |
| `cabinet_sideview.png` / `.svg` | 立面剖视图（三层堆叠）+ 中层俯视布局（泵/阀/气体扩散池）+ 平面图（开门角度） |

重新生成：

```bash
"/c/Program Files/FreeCAD 1.0/bin/freecadcmd.exe" cabinet.py
```

改任何尺寸后都会跑自检，几何冲突会直接报错退出（`SELF-CHECK FAILED` +
`SystemExit(1)`）。

## 关键尺寸

```
外壳            600 × 300 × 500 mm（宽 × 深 × 高），壁厚 3.0 mm（占位值，
                真实产品是买来的 FRP 或 316L，不是这个厚度）
门              铰接在 -X 竖边，摆动 110°，铰链偏置 5 mm 出墙面
                （偏置是必须的 —— 铰轴如果正好落在门板厚度中心，门板
                贴铰链一侧的角在转到 90° 以后会扫进旁边的框柱里）
三层分配（内部高度 494 mm）：
  下层 LOWER    207.5 mm  试剂瓶/废液桶，倾斜集液盘，底部
  中层 MIDDLE   138.3 mm  竖直安装板，泵/阀/气体扩散池单排布置，朝门面朝外
  上层 UPPER    148.2 mm  MCU、驱动板、光学模块，顶部
走线口          Ø20，后壁下部（z = 103 mm，即墙厚 3 + 100），
                符合 §8.5 接地/EMI 要求 —— 从来不从顶部进线
集液盘          四角浅盘，从低点角往对角抬升 8 mm，漏液传感器
                （BOM 第 29 项）正对低点角
湿隔板          10 mm PVC Type 1 / HDPE（BOM 第 32b 项）
```

**三层顺序是硬约束，不只是布局选择**：§8.2/8.4 说漏液会往下走，所以电气
永远在最上面，湿的流路居中，最湿的试剂/废液在最下面且带集液盘。自检里
"wet panel never sits above the electronics tier" 和
"bund tray never sits above the wet-fluidics tier" 两项就是查这个顺序，
不是查尺寸对不对。

## 中层元件几何（泵、阀）

之前的版本泵和阀都是长方体占位。现在换成能看出形状的几何体，是为了让间隙
自检查的是**真实轮廓**，不是留了一堆余量的方盒子：

```
六通阀 × 2      圆柱体阀体 Ø45 × 35 mm，6 个径向接口沿周向等分，
                顶部一个执行器旋钮 Ø20 × 15 mm
                （占地半径 = 阀体半径 + 接口伸出长度 12 mm）
蠕动泵 × 3      电机座 60 × 55 × 45 mm，转子头 Ø45 × 8 mm，
                3 个滚柱围转子头分布，管路绕滚柱缠绕近一整圈
                （缺口 50°，两端各留 15 mm 直管）
```

**泵的占地比电机座大，这是刻意查的**：缠绕的管路半径比电机座宽/深方向都
要大，之前用方盒子占位会漏掉这一点，把泵摆得太近。自检新增了中层每两个
元件的两两相交检查（`middle tier component i/j don't overlap`），专门查
这类被管路/接口伸出部分撑大的真实占地，不能只按标称外壳尺寸留间距。

**改为竖直安装板，单排布置**：泵、阀、气体扩散池原来平铺在水平底板上（占
地摊开在 X/Y，高度方向反而很空）。参考 FIAlab 自家产品资料（FIAlyzer-1000/
FLEX 宣传页：泵+阀装在窄机箱内一块竖直面板上，官方原话是"designed
vertically to minimize footprint"）以及设计文档 §8.4 本身"一块平板加小支架"
的倾向，改成贴中层背墙的一块竖直板，6 个元件（3 泵 + 2 阀 + 1 气体扩散池）
沿板宽方向排成一排，朝门方向伸出。单排是因为中层高度（~138 mm）只够放一排
这些元件的截面，放不下泵排+阀排两层。

几何实现上没有重写泵/阀的滚柱、管路、接口这些几何逻辑——`make_pump_solid`/
`make_valve_solid` 仍按原来"贴地、往 +Z 长"的本地坐标系构建，只是新增了一个
`_mount_on_plate()`，把做好的实体绕 X 轴转 90°再平移，贴到竖直板的正面上，
朝 -Y（门方向）伸出。气体扩散池只是个薄板，直接把 Y/Z 尺寸对调后走同一个
转换函数，不用单独处理。

## 材质分区（摘自 §8.2，下单前必须确认）

| 区域 | 材质 | 原因 |
|---|---|---|
| 外壳 | 买的 FRP 或 316L，NEMA 4X / IP66 | 不要自己做压力边界 —— 买来的密封圈、铰链、锁扣比一次性折弯便宜 |
| 湿隔板 | 10 mm PVC Type 1 或 HDPE | 耐 NaOH + NaOCl，可钻孔攻丝，流路没定型前改起来便宜 |
| 光学模块 | 机加工铝（同 BOM 第 20 项） | 需要热质量稳定 LED，位于滴水区上方，从不被打湿 |
| 电气子板 | 钢或铝 DIN 板，上层 | 接地，屏蔽模拟前端 |
| 集液盘 | 折 316 或模压 PP，向漏液传感器倾斜 | 让 BOM 第 29 项有东西可以检测 |

## 开放决定（这些是占位值，不是选型结论）

设计文档里没有给出泵、阀、试剂瓶、光学模块的**外形尺寸**——BOM 只列了
功能规格和价格。脚本里这些元件都是按常见商用外形猜的占位几何体，只是为了
让间隙自检有真实几何可查，**不代表实际选型**：

```
光学模块            70 × 60 × 15 mm（照抄 gd_cell.py 的 PLATE_X/Y/Z，
                    因为气体扩散池就是那个尺寸的板）
六通阀 × 2          见上一节，阀体 Ø45×35 + 旋钮 Ø20×15 + 6 接口
蠕动泵 × 3          见上一节，电机座 60×55×45 + 转子头/滚柱/管路
500 mL 试剂瓶 × 3   Ø90 × 170 mm
2 L 废液桶          Ø150 × 180 mm
```

选定具体型号（泵、阀、瓶子）后，把这些常量换成真实外形尺寸重新跑一次，
自检会自动核对新尺寸是否还满足每层的间隙要求。

其他仍待定的参数：

- **门铰链偏置 5 mm** 是够用的最小值估计，不是任何铰链规格书查出来的数字。
  选定实际铰链型号后按其数据表核实。
- **三层分配比例 (0.30, 0.28, 0.42)** 现在是猜的，等泵/阀/瓶子的真实尺寸
  定下来后应该按实际占用高度重新分配，而不是继续按比例瞎分。
- **走线口位置** 现按 §8.5 只给了"低、后壁"的方向性要求，具体两个孔的
  X 位置（现在是 ±150 mm）没有依据，等实际走线规划出来再调。
